신뢰성 검사와 한계
  • 자료마다 event_time·available_at·retrieved_at·source를 확인합니다.
  • 현재 종목 목록으로 과거를 덮어쓰지 않고 과거 Git 커밋의 종목 목록을 사용합니다. 당시 상장 원자료 완전성이 미검증이면 생존편향 해소 완료로 표시하지 않습니다.
  • 현재 엔진의 Python 소스를 그대로 실행합니다. 당시 저장 신호와 현재 엔진의 과거 입력 재계산은 별도로 표시합니다.
  • 분석 시각 이전 가장 최근 저장 자료를 사용합니다. 스냅샷 간격과 누락·지연 데이터 때문에 정확한 당시 전체 시장 상태를 보장하지 않습니다.
  • 중국계 여부가 당시 검증되지 않았다면 회사명만으로 추정하지 않습니다.
  • 성과를 보고 후보를 고르거나 점수·임계값을 수정하지 않습니다.
